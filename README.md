# Стройка — приложение для похудения с подсчётом калорий и БЖУ

Нативное Android-приложение на Kotlin (Material 3). Работает полностью офлайн:
все данные хранятся только на устройстве, интернет не требуется.

## Что умеет

**Дневник питания**
- Подсчёт калорий и БЖУ по четырём приёмам пищи (завтрак, обед, ужин, перекусы)
- Кольцо прогресса с остатком калорий и полосы Б/Ж/У с фактическими и целевыми граммами
- Переключение по дням (стрелки «вперёд/назад»), итог за день, удаление записи с отменой
- Счётчик воды с целью и шагом +250 мл
- Добавление продуктов из базы, из «избранного», своих продуктов или целиком из рецепта

**База продуктов — 251 позиция**
- Овощи, фрукты, ягоды, мясо и птица, рыба и морепродукты, молочное и яйца,
  крупы/макароны/бобовые, орехи и семена, масла, хлеб и выпечка, сладости, напитки, соусы, готовая еда
- Ккал, белки, жиры и углеводы на 100 г, поиск по названию, фильтр по категориям
- Избранное (звёздочка) и свои продукты — сохраняются между запусками

**Подбор диет — 11 программ**
Сбалансированный дефицит, белковая (Дюкан), кето, умеренная низкоуглеводная,
средиземноморская, вегетарианская, веганская, безглютеновая, интервальное голодание 16:8,
японская, для спорта. По каждой — правила, пример меню на день, плюсы и минусы.

Подбор персональный: приложение ранжирует программы по совпадению с вашим
калоражем, предпочтениями (веганство/вегетарианство/низкоуглеводность/без глютена),
уровнем активности и целью — и объясняет, почему подходит именно эта диета.
Применённая диета пересчитывает цели по калориям и БЖУ.

**Рецепты — 46 блюд с БЖУ**
- Калории и БЖУ считаются автоматически из ингредиентов, поэтому всегда согласованы с базой
- Ингредиенты с граммами и калорийностью, пошаговое приготовление, время и число порций
- Фильтр по типу диеты, поиск по названию блюда или продукта
- Кнопка «Добавить в дневник» переносит все ингредиенты порции в выбранный приём пищи

**Профиль и трекер веса**
- Пол, возраст, рост, вес, целевой вес, активность, цель и темп снижения
- Расчёт по формуле Миффлина–Сан Жеора: BMR, TDEE, калории на день с дефицитом, нормы Б/Ж/У, ИМТ
- График динамики веса с линией цели, расчёт остатка до цели и прогноз сроков в неделях
- Сброс данных, смена активной диеты, цель по воде

## Установка

1. Скопируйте `Stryka-1.0-release.apk` на телефон с Android 7.0 (API 24) или новее.
2. Откройте файл и разрешите установку из неизвестных источников, если система попросит.
3. Запустите приложение «Стройка».

Приложение не запрашивает ни одного разрешения и не обращается к сети.

## Сборка из исходников

```bash
# JDK 17, Android SDK (platform 34, build-tools 34.0.0)
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleRelease      # сборка подписанного APK
./gradlew :app:testDebugUnitTest    # тесты (22 юнит-теста + 7 UI-smoke-тестов)
```

Подпись релиза: `keystore/stroyka-release.jks` (пароль `stroyka2024`, alias `stroyka`).
Приватный ключ лежит в репозитории — замените его своим перед публикацией в Google Play.

## Структура

```
app/src/main/java/com/stroyka/fit/
  data/       Models.kt, FoodDb.kt (251 продукт), RecipeDb.kt (46 рецептов),
              DietDb.kt (11 диет), Calc.kt (расчёты и подбор), Store.kt (хранилище), Dates.kt
  ui/         MainActivity, DiaryFragment, FoodsFragment, RecipesFragment,
              DietsFragment, ProfileFragment, AddFoodActivity,
              RecipeDetailActivity, DietDetailActivity, Views.kt (кольцо и график), Adapters.kt
```

Технологии: Kotlin 1.9, AGP 8.5, Material 3, ViewBinding, SharedPreferences + JSON
(без внешней БД и без аннотационных процессоров), Robolectric для UI-тестов и рендера скриншотов.

## Оговорка

Расчёты БМР/ТDEE — ориентировочные (формула Миффлина–Сан Жеора), значения в базе
продуктов — усреднённые справочные данные. При заболеваниях, беременности или
приёме лекарств проконсультируйтесь с врачом.
